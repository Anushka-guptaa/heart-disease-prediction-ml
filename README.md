# ❤️ Heart Disease Prediction using Machine Learning

A Machine Learning project that predicts the likelihood of heart disease using patient health parameters.
The project uses synthetic healthcare data for training and testing purposes while demonstrating the complete ML workflow, including preprocessing, visualisation, model training, and evaluation.

---

## Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Synthetic dataset generation
- Machine Learning model training
- Model evaluation using accuracy and metrics
- Heart disease prediction system
- Visualisation of results

---

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
---

## Dataset

This project uses a synthetic dataset generated to simulate real-world heart health records.

### Why Synthetic Data?

- Avoids privacy issues related to real medical data
- Safe for academic and demonstration purposes
- Helps simulate healthcare prediction systems
- Allows controlled testing and experimentation

Features used may include:

- Age
- Blood Pressure
- Cholesterol
- Heart Rate
- Smoking Status
- Diabetes
- Chest Pain Type
- Exercise Levels
- ECG Results

---

## 🧠 Machine Learning Workflow

1. Data Collection
2. Data Cleaning
3. Feature Selection
4. Data Visualisation
5. Model Training
6. Model Evaluation
7. Prediction Generation

---

##  Model Evaluation

The model performance is evaluated using:

* Accuracy Score
* Confusion Matrix
* Precision
* Recall
* F1-Score
